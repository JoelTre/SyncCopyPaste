About

SyncCopyPaste allows you to drag and drop or copy-paste any text, images, other files or folders between any two devices.

SyncCopyPaste was developed in New Zealand by Joel Tregurtha using Codex.

  • End-to-end encrypted
  • Works across Windows, Linux, Mac, iOS, and Android
  • No account or install required
  • Super easy to use
  • 100% free and open source

How this app works

The connection link contains a room code and passcode. The room code is like the name of a meeting place; the passcode helps restrict who can meet there. The devices use these to find each other using a peer-to-peer networking library called Trystero. Trystero uses internet signalling services to help the devices find each other.

The devices then use WebRTC (Web Real-Time Communication) to find a working network route and establish an encrypted connection. When a direct route is not available, Cloudflare can relay the encrypted data. Keep the connection link private: anyone with it can attempt to join the room.

Files and text travel between the devices over that WebRTC connection. Shared items are held in each open page’s memory. Closing the page or ending the connection clears its list; downloading a file saves a separate copy. Paired devices are remembered in this browser so you can reconnect later. Clearing browser data removes them; forgetting a device here does not remove it from the other device.

Optional clipboard sync reads supported clipboard content with your browser's permission and sends it through the same connection. Browser restrictions may prevent automatic clipboard access.

Optional folder connection lets both devices browse a selected folder and its subfolders. When both devices connect folders, Split view can copy files between them through the encrypted connection. Read and write permissions and browser support are required.

These features currently only work on some devices
