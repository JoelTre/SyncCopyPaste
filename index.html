How this app works

The connection link contains a room code and passcode. The devices use them to find each other through a service called Trystero and establish an encrypted WebRTC connection. Trystero is a serverless peer-to-peer networking library that helps the devices find each other and exchange messages. WebRTC (Web Real-Time Communication) is a free, open-source browser technology that lets devices communicate directly in real time.

Files and text travel over that connection between the devices, end-to-end encrypted. Network services help the devices find a route, and may relay the encrypted data when a direct connection is not possible.

Shared items are held in each open page's memory. Closing or disconnecting a page removes its list; downloading a file saves a separate copy. The link grants access to the room, so keep it private. Paired devices are remembered in this browser so you can reconnect later. Clearing browser data removes them; forgetting a device here does not remove it from the other device.

Optional clipboard sync reads supported clipboard content with your browser's permission and sends it through the same connection. Browser restrictions may prevent automatic clipboard access.

Optional folder connection lets you select a folder to browse from the other device, including its subfolders. The folder stays on your device, and files are sent through the same encrypted connection when requested. Browser support and permissions are required.
