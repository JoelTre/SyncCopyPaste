# SyncCopyPaste
A free, open-source web app for copying text, images and other files between any two devices.

[Open SyncCopyPaste](https://synccopypaste.app)


SyncCopyPaste allows you to drag and drop or copy-paste any text, images, other files or folders between any two devices.

SyncCopyPaste was developed in New Zealand by Joel Tregurtha using Codex.

* End-to-end encrypted
* Works across Windows, Linux, Mac, iOS, and Android
* No account or install required
* Super easy to use
* 100% free and open source
